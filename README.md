# HR Performance & Workforce Reporting Dashboard

*Dataset Source*: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

*Tools*: Power BI • SQL Server • Excel • Power Query

An automated HR analytics reporting system built using SQL Server, Excel VBA, and Power Query to generate HR KPIs and export daily dashboards as PDFs.

This project focuses on improving the quality, clarity and reliability of workforce-style data by creating a structured reporting workflow and KPI dashboard. The goal was to turn inconsistent employee-related data into accurate, decision-ready insights, closely reflecting the type of work required in workforce reporting and data governance roles.

## Key contributions:

1. Cleaned and validated workforce-type data, including attendance, performance indicators and activity logs, to remove duplicates, inconsistencies and formatting errors.

2. Standardised KPI definitions (e.g., attendance %, performance clusters, engagement metrics) to ensure reporting accuracy.

3. Developed automated data-preparation steps using SQL and Power Query to reduce manual effort and minimize errors during refresh cycles.

4. Designed a Power BI dashboard presenting clear, structured workforce insights such as performance trends, attendance patterns and risk indicators.

5. Documented data assumptions, business logic and transformation steps, improving clarity and traceability for future users.

6. Ensured reporting consistency by applying governance practices such as field naming conventions, validation rules and metadata organisation.

## Why this project matters:
The approach directly reflects the skills needed in workforce systems and data-governance roles especially improving reporting accuracy, validating people-related data and building reliable, repeatable reporting processes.
